# ルーン占い一枚引きアプリ PRD

## 概要
エルダーフサルク25文字（空白ルーン含む）を使ったルーン占いの一枚引きアプリ。

## 機能
### コア機能
- **ルーン一枚引き**: タップでランダムにルーンを1つ引く
- **正位置/逆位置**: 逆位置可能なルーンは正逆をランダム判定
- **結果表示**: ルーンシンボル、名前、意味、解釈を表示
- **占い履歴**: 過去の占い結果を保存・閲覧・削除

### 25ルーン
エルダーフサルク24文字 + 空白ルーン（ウィルド/Wyrd）

## デザイン
- テーマ: 深い森の中で光る宝を見つけたようなデザイン
- 配色: ダークグリーン(#06140D) + ゴールド(#D4AF37)
- 背景: 神秘的な森のイメージ + ダークオーバーレイ
- フォント: Cormorant Garamond (見出し) + Manrope (本文)

## 技術スタック
- Frontend: React Native (Expo SDK 54) + expo-router
- Backend: FastAPI + MongoDB
- ナビゲーション: タブベース（ルーン引き / 履歴）

## API エンドポイント
- POST /api/draw - ランダムルーン引き
- POST /api/readings - 占い結果保存
- GET /api/readings - 履歴取得
- DELETE /api/readings - 履歴全削除
